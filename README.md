# Kaysons Techno Equipments website

Static Kaysons website for GitHub Pages. No npm, Node.js or Render is required.

Main navigation pages: Home, Product Portfolio, About Us and Contact. A compact Legal page contains the Privacy Policy and Website Terms.

The design follows the supplied editorial studio reference: Onest typography, soft rounded surfaces, black feature cards, Kaysons-red accents, pill controls, spring-like reveals, count-up statistics and a large CTA footer. Desktop uses a complete navigation bar; the menu overlay is mobile-only.

The package includes a branded first-visit 000–100 preloader, restrained section reveals, product search and filtering, product-media/download provisions, a Google Maps preview, SEO metadata, structured data, a consent-based GA4 provision and EmailJS-ready enquiry forms. The loader is skipped automatically when navigating between pages in the same browser session.

Final product photographs, datasheets, catalogues, certificates and product-specific filter values can be connected in `product-assets.js`. Every product card is already prepared, so these files can be added without redesigning the pages.

Open `index.html` locally to review the site. Before publishing, follow `SETUP_EMAILJS_ANALYTICS.md` to activate EmailJS and optional analytics with the account-specific public IDs.
