# Asset provenance

- Kaysons logo, compact mark and approval marks: retained from the user-supplied website package. Approval scope remains product-specific.
- Onest: variable font from the official Google Fonts Onest source, subset to Latin/extended Latin, punctuation, currency and arrows and packaged as WOFF2. The SIL Open Font License is included at `assets/fonts/Onest-OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/onest
- `assets/engineering-study.webp`: original generated abstract material-study artwork, converted to WebP for web delivery. It does not represent a supplied Kaysons product or factory photograph. The homepage caption identifies it as a material study.
- Interface icons: simple functional SVG paths for arrows, search, filtering, menus, selection and closing; no third-party icon runtime is required.
